# TerraSense

Жорлон орчмын хөрсний түргэвчилсэн био-тестийн уншилт, цэг бүрийн өөрчлөлт, био-бэлдмэлийн хэрэглээг хянах монгол хэлтэй вэб апп. Утас болон компьютерийн хөтөч дээр ажиллана.

## Ажиллуулах

Node.js 22 ашиглана. Гаднын npm хамаарал суулгах шаардлагагүй.

```sh
npm run dev
```

Хөтөчдөө [локал аппыг](http://127.0.0.1:4173/) нээнэ. Анх **Демо орчин** нээгдэж, 12 жишээ цэгийн зургаан сарын зохиомол уншилтыг харуулна. Өөрийн талбайн ажлыг эхлүүлэхдээ **Тохиргоо → Миний бүртгэлийг нээх** товчийг сонгоно. Миний бүртгэл, демо болон багийн сан тусдаа хадгалагддаг. HTTPS-д байршуулсны дараа утасны хөтчийн цэснээс үндсэн дэлгэцэд нэмж, тусдаа аппын цонхоор нээж болно.

## Талбай дээр ашиглах

1. **Шинэ био-тест** дээр дарж цэг сонгох эсвэл нэр, координат оруулан цэг үүсгэнэ. Утасны GPS-ээс байршил авч болно.
2. Үйлдвэрлэгчийн бага, дунд, өндөр ангиллын лавлах өнгө болон тестийн үр дүнг нэг гэрэлд хамтад нь зураг авна. Камер, хадгалсан зураг, гар бүртгэл гэсэн гурван оролттой.
3. Зурган дээр сорьц болон гурван лавлах хэсгийн төвийг сонгоно. Апп медиан RGB өнгийг OKLab орон зайд харьцуулна. Сонголтууд давхцсан, өнгө жигд бус, лавлахууд ялгагдахгүй, эсвэл сорьц лавлахад тохирохгүй үед шалтгааныг харуулж **Тодорхойгүй** ангилал өгнө. Дахин сонгох, шинээр зураг авах, эсвэл тодорхойгүй дүн хадгалах боломжтой. Зураг төхөөрөмж дээр боловсруулагдана. Өнгөний утга, эцсийн ангилал, тайлбар хадгалагдана.
4. Ажиглалт хийсэн огноо, цагийг Улаанбаатарын цагаар оруулна. **GIS газрын зураг** дээр цэг, дүүргээр хайж, цэгийн түүхээс давтан тест эсвэл сануулга шууд үүсгэнэ.
5. **Давтан хэмжилт** тайланд нэг цэг дээр ижил нэртэй иж бүрдлээр хоёр өөр өдөр авсан тодорхой уншилтуудыг харьцуулна. Тухайн өдрийн сүүлийн уншилтыг ашиглаж, олон иж бүрдэл байвал харьцуулах боломжтой хамгийн сүүлийн хосыг сонгоно. Цэгийг нэг удаа тоолно. Тайланг хугацаа, дүүрэг, өөрчлөлтөөр шүүж болно. Самбарын сарын график тухайн сарын сүүлийн уншилт нь тодорхой байсан цэгүүдээс өндөр ангилалтай цэгийн хувийг харуулна.
6. **Сануулга** хэсэгт бүтээгдэхүүний нэр, шошгонд заасан хэмжээ, нэгж, өдрийг оруулна. **Товыг давтах**-ыг сонгож хоногийн зайг оруулбал гүйцэтгэл бүртгэхэд төлөвлөсөн өдрөөс тоолон дараагийн тов нэг удаа үүснэ. Гүйцэтгэлийг буцаахад холбогдох хүлээгдэж буй тов цуцлагдана. Дараагийн товыг аль хэдийн гүйцэтгэсэн бол сүүлийн гүйцэтгэлээс эхэлж буцаана.
7. **Хуанлид нэмэх** товчоор одоо хүлээгдэж буй товуудын 09:00 цагийн дохиотой `.ics` файлыг татна. Утасны хуанлид импортолж, мэдэгдлийг идэвхжүүлнэ. Аппад шинээр үүссэн товыг хуанлидаа дахин импортолно.

**Хувийн өгөгдлөө шилжүүлэх.** **Миний бүртгэл → Тохиргоо → Нөөцлөх, сэргээх** хэсгээс цэг, тест, сануулгаа JSON файлд татна. Нөгөө төхөөрөмжид энэ файлыг сонгоход шинэ, ижил, зөрчилтэй мөрийн тоог урьдчилан харуулна. Ижил бүртгэлийг алгасаж, шинэ бүртгэлийг нэг үйлдлээр нэмнэ. Ижил дугаартай хоёр өөр утга эсвэл давтамжтай товын зөрчил байвал хадгалахаас өмнө файлыг засна. Нөөц файлын дээд хэмжээ 16 МиБ.

Демо цэг, уншилт, тун нь үзүүлэнгийн зориулалттай. Бодит хэрэглээнд сонгосон тестийн үйлдвэрлэгчийн лавлах карт, ангилал, унших хугацааг дагана. Тухайн бүтээгдэхүүн, хөрсний нөхцөл, утасны камер дээр ангиллын нарийвчлалыг талбайн болон лабораторийн харьцуулалтаар баталгаажуулах шаардлагатай.

## Vercel-д байршуулах

1. Энэ хавтсыг `api/`, `src/`, `assets/`, `scripts/` болон `vercel.json`-тай нь Git репозиторт оруулна.
2. Vercel-ийн **New Project** хэсгээс репозитороо импортолж, `package.json` байрлах хавтсыг **Root Directory** болгоно.
3. `vercel.json` нь **Other** тохиргоо, `npm run build` команд, `dist` гаралтыг заана. **Deploy** хийхэд Vercel статик апп болон `/api/workspace` функцийг хамт байршуулна. Камер болон GPS нь HTTPS хаяг дээр хэрэглэгчийн зөвшөөрлөөр ажиллана. [Vercel build тохиргоо](https://vercel.com/docs/builds/configure-a-build) · [Node.js функц](https://vercel.com/docs/functions/runtimes/node-js)

Демо болон хувийн горимд орчны хувьсагч шаардахгүй. Эхний онлайн нээлтээр service worker бэлэн болсны дараа эдгээр горимд офлайн нээх, бүртгэл нэмэх боломжтой. Төхөөрөмжийн бүртгэл IndexedDB-д хадгалагддаг тул хөтчийн site data-г арилгахад устна. Био-тестүүдийг CSV хэлбэрээр татаж болно.

### Багийн өгөгдлийн сан

Upstash Redis үүсгээд Vercel-ийн **Settings → Environment Variables** хэсэгт дараах утгыг тохируулж дахин deploy хийнэ. [Upstash REST API](https://upstash.com/docs/redis/features/restapi) · [Vercel орчны хувьсагч](https://vercel.com/docs/environment-variables)

| Нэр | Утга |
| --- | --- |
| `UPSTASH_REDIS_REST_URL` | Upstash REST endpoint |
| `UPSTASH_REDIS_REST_TOKEN` | Серверийн бичих эрхтэй Redis токен |
| `WORKSPACE_ACCESS_TOKEN` | Багийн гишүүдэд өгөх тусдаа, санамсаргүй, 32 ба түүнээс олон тэмдэгттэй түлхүүр |

**Тохиргоо → Багийн сантай холбох** хэсэгт зөвхөн багийн нэвтрэх түлхүүрийг оруулна. Багийн сан хоосноос эхэлнэ. Нэг багийн түлхүүртэй гишүүд бүгд унших, бичих эрхтэй. Хөтөч багийн түлхүүрийг тухайн табын session storage-д хадгална. Багийн ажиллагаанд серверийн холболт хэрэгтэй. Preview болон Production өгөгдлийг тусгаарлахдаа өөр Redis сан, багийн түлхүүр тохируулна.

Сервер оролтыг шалгаж, нэг үйлдлийн цэг ба хэмжилтийг хамтад нь хадгална. Өөр бүртгэлийн зэрэгцээ өөрчлөлтүүд нийлж, нэг бүртгэлийг зэрэг зассан бол зөрчил мэдээлнэ. Энэ хувилбар нэг багийн сериалчилсан өгөгдөлд 1 MiB, нэг өөрчлөлтийн хүсэлтэд 64 KiB хязгаартай. Локалд багийн API-г туршихдаа `.env.example`-ийг `.env.local` болгон хуулж утгуудыг тохируулна.

## Шалгалт

```sh
npm test
npm run build
npm start
```

`npm start` нь бэлтгэсэн `dist/` болон ижил API функцийг локалд ажиллуулна. Автомат тестүүд API нэвтрэлт, өгөгдлийн баталгаажуулалт, зэрэгцээ бичилт, календарийн файл, хугацааны бүс, сарын статистикийг шалгана. API тестэд Redis-ийн REST хариуг дуурайлгана.

## Судалгаа ба газрын зургийн эх сурвалж

- **Akvo Caddisfly** утсаар уншсан тестийг байршил болон талбайн тэмдэглэлтэй холбодог. TerraSense энэ зарчмыг сорьцын өнгө, лавлах өнгө, хүний баталгаажуулсан ангиллыг нэг бүртгэлд хадгалахад ашигласан. [Akvo-ийн Мали дахь хэрэгжилт](https://akvo.org/stories/west-africa/digitising-water-quality-testing-and-monitoring-in-mali-with-somagep/)
- **ArcGIS Field Maps** нэг объектод давтан ажиглалт холбож, талбайд офлайн ажиллах боломж олгодог. TerraSense хотын суурь зургийг апптай багцалж, цэг бүрийн уншилтын түүхийг хөтөлдөг. [ArcGIS Field Maps](https://doc.esri.com/en/arcgis-field-maps/latest/get-started/get-started.html)
- Улаанбаатарын суурь зурагт OpenStreetMap, OpenFreeMap, OpenMapTiles болон Mapzen Terrain-ийн мэдээлэл ашигласан. Хотын хамрах хүрээнээс гадна болон гудамжны өндөр томруулалтад OpenStreetMap-ийн хавтанг онлайн ачаална. [OpenStreetMap attribution](https://www.openstreetmap.org/copyright) · [OpenFreeMap](https://openfreemap.org/) · [OpenMapTiles](https://openmaptiles.org/) · [Mapzen Terrain эх сурвалж](https://github.com/tilezen/joerd/blob/master/docs/attribution.md)
- Inter фонтыг SIL Open Font License-аар багцалсан. Лиценз `assets/inter-license.txt` файлд бий.
- Нүүрний гэр хорооллын панорам нь ImageGen-ээр бүтээсэн дүрслэл. Газрын зураг дээрх байршлын өгөгдлийн эх сурвалжийг дээр дурдсан.
